# ASCENT — Development Roadmap

## Phase 0 — Foundation
Goal: establish a stable development base.

### Frontend
- Repository setup
- Next.js + TypeScript
- Tailwind and component foundation
- Routing structure
- Shared layouts
- Authentication screens
- API client foundation
- Query/state foundation
- Loading/error primitives
- Public page shell

### Backend
- FastAPI project structure
- Environment configuration
- API versioning strategy
- Health endpoint
- Authentication integration
- Core schema conventions
- Database connection
- Initial domain boundaries

### Infrastructure
- Git branching workflow
- Preview deployments
- Environment variable conventions
- CI quality checks

## Phase 1 — Core Product
- User profiles
- Opportunity creation and discovery
- Opportunity details
- Applications
- Application status tracking
- Basic admin workflows

## Phase 2 — Operational Workflows
- Application review
- Selection workflows
- Event capabilities
- Notifications
- Improved administrative tooling

## Phase 3 — Experience and Intelligence
- Refined public experiences
- Selective 3D storytelling
- AI-assisted features where validated
- Analytics and optimization

## Development Order
Foundation → Core Data → Core Workflows → Admin Operations → Experience Enhancements → Intelligence

Do not reverse this order merely because the shiny feature is more fun to demo.
