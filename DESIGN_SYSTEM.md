# ASCENT — Design System

## Design Philosophy
ASCENT should feel:
- Modern
- Ambitious
- Technological
- Premium without being excessive
- Clear and usable for productivity workflows

## Experience Split

### Public Experience
- Strong visual storytelling
- Rich motion
- Selective immersive 3D
- Brand-driven composition
- Progressive enhancement

### Application Experience
- Clarity first
- Fast interactions
- Accessible controls
- Minimal distracting motion
- Information hierarchy over spectacle

## Component Principles
Components should be:
- Reusable
- Accessible
- Responsive
- Consistent
- Composable

## Required UI States
Where applicable, components and pages should account for:
- Default
- Hover
- Focus
- Active
- Disabled
- Loading
- Empty
- Error
- Success

## Responsive Strategy
Support:
- Mobile
- Tablet
- Desktop
- Large desktop

Do not design desktop-first interfaces and merely crush them into mobile widths afterward.

## 3D Rules
3D may enhance approved public pages only.
It must:
- Support graceful fallback
- Be lazy loaded
- Avoid blocking core content
- Respect reduced-motion preferences where possible
- Have a performance budget
