# ASCENT — Features

## Core User Features

### Authentication
- Sign up
- Sign in
- Sign out
- Password recovery
- Session handling

### User Profile
- Personal profile
- Bio and relevant information
- Skills/interests as product requirements evolve
- Profile editing

### Opportunities
- Browse opportunities
- View details
- Search and filtering
- Deadlines and status

### Applications
- Submit applications
- Validate application input
- Track status
- View application history

### Events
- Browse events
- View event details
- Event-related participation flows as defined per feature

## Organizer / Admin Features

### Opportunity Management
- Create
- Edit
- Publish
- Close/archive

### Application Management
- View applicants
- Review submissions
- Update status
- Selection workflow

### User Management
- View users
- Apply role-based administrative controls

## Public Features
- Landing experience
- ASCENT story and identity
- Public opportunity discovery
- Public events
- Selected immersive 3D experiences

## Future Features
These are intentionally not treated as Phase 0 requirements:
- Advanced AI assistance
- Recommendation engines
- Complex analytics
- Automated matching
- Advanced notification workflows
- Gamification

Future features must not distort the foundation architecture prematurely.
